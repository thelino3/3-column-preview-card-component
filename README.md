# 📚 Library Management System

A modern, web-based Library Management System built with Python, Flask, and Bootstrap 5. Features a Glassmorphism UI, secure Admin authentication, and live API integrations.

## ✨ Features
* **Live Search API:** Automatically fetches real-world book data (Title, Author, Category) from the Google Books API while typing to prevent spelling errors.
* **Role-Based Security:** Public catalog browsing for guests. Secure login required for Admins to add/delete books and manage members.
* **Smart Validation:** Prevents duplicate book entries, duplicate University IDs, and double-borrowing.
* **Responsive UI:** Custom Glassmorphism design with animated gradients, fully optimized for mobile and desktop screens.
